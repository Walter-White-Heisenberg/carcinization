# Data and provenance

The selected-paper manifest contains public bibliographic metadata and SHA-256 hashes. Original articles remain under their respective authors' and publishers' terms; this repository distributes links, not copies of the papers or their source packages.

No private issue gold set, annotator roster, personal account configuration, full provider request/response archive, or local terminal transcript is included. Evidence and raw outputs may be released separately after checking permissions and separating author evidence from generation inputs.

The present paper list is a preparation artifact, not a preregistration lock or permission to incur API charges. The latest arXiv versions are pinned as of the recorded check; subsequent author updates do not silently alter an already frozen experiment.
